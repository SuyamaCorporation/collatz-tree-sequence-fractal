# Collatz 3n+1 Conjecture Tree Fractal Draw

Visualizes all Collatz sequences for numbers 1–200 as a branching tree rooted at 1, drawn on a canvas. Each path traces the 3n+1 rule backward from 1 outward, color-coded by starting number in a rainbow gradient. Hover over any branch to highlight that number's path and see its step count.

## Features

- Tree layout showing all Collatz paths simultaneously branching from root node 1
- Rainbow color gradient mapping each starting number to a unique hue
- Hover highlight showing individual paths with step count tooltip
- Adjustable max N (20–200) and spread angle controls with instant redraw
- Zoom with scroll wheel and pan by dragging the canvas
